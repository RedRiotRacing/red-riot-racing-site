## Install (Mac)
1. Select `redesign-preview` in GitHub Desktop, pull changes, and ensure working tree is clean.
2. Unzip this package.
3. Run `INSTALL-V5-PREVIEW.command` and choose your repository root folder.
4. The installer backs up your repository and preserves your current data/media, while adding the site updates.
5. Review, commit, and push. Inspect the Cloudflare preview before merging to main.

`README-CONSOLIDATED.txt` and `VERSION-HISTORY-CONSOLIDATED.txt` contain the consolidated legacy notes.
