First-time setup

The website files must first be uploaded to a GitHub repository, the repository connected to Cloudflare Pages, and the Pages CMS GitHub App authorized. See the included README.md for setup steps. This page is a link to the secure external editor, not a built-in login system.

No public editing access is provided by this page. Only people given GitHub/Pages CMS repository permissions can save changes.
